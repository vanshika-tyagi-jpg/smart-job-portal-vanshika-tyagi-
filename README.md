# Smart Job Portal (MERN Stack)

A full-stack job portal web application where users can register, login, browse jobs, and apply to them.

---

## Features

- User Authentication (JWT)
- Register & Login system
- Create, View, Delete Jobs
- Apply to Jobs
- View My Applications
- Protected Routes

---

## 🛠 Tech Stack

- Frontend: React.js + Tailwind CSS
- Backend: Node.js + Express.js
- Database: MongoDB
- Authentication: JWT

---

## ⚙️ How to Run Locally

### Backend
cd backend  
npm install  
npm start  

### Frontend
cd frontend  
npm install  
npm start
